# Publication checklist

The original `recurrent_racer` project and all historical experiments are preserved locally. This copy uses fresh Git history containing only the curated publication content. The original project is not connected to the publication remote.

## Ready for review

- Final SAC learner with shared Unity utilities; earlier learning implementations excluded.
- Complete source environment, package specifications and native macOS build entrypoint.
- Selected inference actor and initialization export, hashes and explicit selection lineage.
- Recorded original-start/approach evaluation evidence and bounded contract comparisons.
- Real hero/perception GIF and MP4, editable diagrams and data-derived performance figure.
- Setup, training, evaluation, capture and validation documentation.
- Ignore rules for Unity-generated state, builds, Python environments and bulk experiments.

## GitHub destination

The owner authorized public publication under `d-kwong` on 2026-10-01. The destination is [d-kwong/recurrent-racer](https://github.com/d-kwong/recurrent-racer). Only this curated copy is pushed; the original project is preserved locally.

The project license remains **unset**. No general reuse license has been inferred from public visibility or applied automatically. A license can be added later at the owner's direction; see [rights and attribution](THIRD_PARTY_NOTICES.md).

## Validation limits

Source/player and bounded runtime checks passed locally using the existing Python 3.10 environment. A fresh dependency installation, clean-machine end-to-end setup, other operating systems, multiple training seeds and held-out tracks remain untested. Generated players are kept as local-only outputs; a release build would need a separate distribution decision.

## Excluded, retained in the original project

PPO/REINFORCE trainers and analyses; abandoned experiment configurations; historical ONNX policy; all raw bulk logs, intermediate checkpoints and replay buffers; virtual environments/wheels; Library/Temp/Logs/UserSettings/IDE folders; unrelated sample scene/tutorial/readme; personal handoffs, Unity cloud account identifiers, stale template/debug references and unrelated historical documents. Selected SAC comparison records and explicit initialization provenance are carried into this copy. Nothing in the original project was deleted for curation.
