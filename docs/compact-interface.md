# Compact environment interface

`--track-mode procedural --track-layout compact` selects `compact-circuit-v1`; `--track-layout open` retains `open-arcs-v1`. Bare Python `view` now resolves the accepted compact seed 1009, original start and unchanged hash-verified procedural actor from `configs/quality/accepted-view.json`. Explicit `--checkpoint`, `--track-mode`, `--track-layout` or `--config` disables accepted-view injection; explicit CLI values remain authoritative. Other Python commands retain their existing parser defaults. Fixed mode remains the exact bypass. The Unity parameter is `racing_track_layout` (0 open, 1 compact). Native players default to compact seed 1009; `--racing-compact` selects compact, `--racing-open` selects the historical open generator (and takes precedence if both layout flags appear), and `--racing-fixed` preserves the fixed bypass. Python always sets layout explicitly.

Compact uses five straight/arc sections: one opposite-direction bend followed by an equal return bend, then three rounded corners summing to 270 degrees, mirrored by a seeded direction choice. Compact seeds use an avalanche mixer before the existing xorshift sampler, avoiding correlated first draws across adjacent seeds; open sampling is untouched. The first two angles use 25–35 degrees within the configured minimum; first/second circuit corners use 85–95 degrees and the last balances their total. Straights and radii retain configured ranges; tail length is 20 m. Requirements: five sections, radius minimum >=22, angle range covering 35–100, road 9 m and curb 1 m. Sampling spacing retains its configured value. Realized turn angles/radii, all points, accepted attempt, configuration and generator version are recorded in `RACING_TRACK`.

Reject up to 256 deterministic candidates using the existing 15 m nonlocal centerline clearance, offset-boundary validity, road-bounds aspect <=1.6 and span/route-length <=0.40. Failure throws without replacing active geometry. Start/finish remain open, gates/spawn/sensors/collision boundaries use the same accepted record. Public `ProceduralTrack.Generate(seed, parameters, roadWidth=9, curbWidth=1, layout=0)` retains existing callers. Parent approved promotion after eight clean development routes, forty clean untouched routes, and five preselected full chase/overview demonstrations with exact trace parity. Evidence is recorded in `results/compact/capture-gate.json` and `results/compact/held-out.json`; accepted geometry parameters are explicit in the accepted-view manifest.

Curbs use independent renderer strips alternating red/white every exact 4 m of centerline arc length. Existing sensor/collision ribbons are unchanged; curb strips have no collider. Generated white materials are released with meshes. Regeneration sources road/red materials exclusively from preserved fixed geometry, so white tiles cannot become the next route's red base.

## Passive pose event

`RacingAgent.PoseSampled` emits a `RacingPoseSample` only when subscribed: initial reset tick 0, each completed physics tick, and the terminal completed tick before episode reset. Terminal samples replace that tick's ordinary sample. Fields: `tick`, `simulatedSeconds`, `position` (world Vector3 metres), `rotation` (world Quaternion x/y/z/w), `steeringDegrees` (actual vehicle angle), `speedMetresPerSecond` (body velocity magnitude), `seed`, `sequenceIndex`, `geometrySha256`, `taskSha256`, `terminalReason` (None/Crash/OffTrack/InvalidProgress/Finish/NoProgress/Timeout), `interrupted`. Fixed routes use seed -1 and empty hashes. Sampling never queries sensors or writes actor/physics/reward state. Testing owns the opt-in CSV subscriber and output flag, exporter and execution.

Geometry selection precedes driving: development 50000–50007, training 40000–40031, untouched test 60000–60039. Parent owns acceptance and any later default promotion.

`RacingAgent.ObservationSampled(int physicsTick, float elapsedSeconds, float[] observationBuffer)` fires at the end of every `CollectObservations`, including terminal deliveries, after the same single sensor fill supplied to ML-Agents. Subscribers synchronously copy the reused 15-value buffer. Full observation values and ordered sample index are used to align NPZ action-bearing observations; terminal observations are separate. No extra ray queries occur.
