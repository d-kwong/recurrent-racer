# Recorded checkpoint replay interface

Rendered player opt-in: `--portfolio-replay /absolute/manifest.json --portfolio-capture /absolute/output`. Normal driving, evaluation and headless training never install the component. `PortfolioPresentation` first prepares the shared formula-car meshes/backdrop and bypasses its driving HUD/capture in replay mode.

Manifest fields: `seed`, `geometrySha256`, `parameters` (complete actual TrackParameters), `originalSpawn: true`, `durationSeconds` (maximum actual terminal simulated seconds), `terminalHoldSeconds` (additional final display hold), `runs` (exactly four records in checkpoint order). Each run contains `steps`, `poses` (CSV path relative to manifest), `policy_sha256`, `initialization`, `terminalReason`, `interrupted`. Expected steps are 4006, 8018, 12210, 16248. Fixed-policy initialization is the preserved procedural trunk/mean, evaluated independently with identical original start.

Testing extracts each requested episode as a standalone CSV from passive `PortfolioPoseRecorder` telemetry. The header is `tick,simulated_seconds,position_x,position_y,position_z,rotation_x,rotation_y,rotation_z,rotation_w,steering_degrees,speed_metres_per_second,seed,sequence_index,geometry_sha256,task_sha256,terminal_reason,interrupted`. Rows include actual tick zero and contiguous physics ticks through the terminal tick. Replay rejects different seed/geometry, different initial poses, nonfinite values, multiple episodes, missing terminal and mismatched duration. Generator config comes directly from the manifest and must reproduce its geometry hash.

Replay disables the live agent, vehicle, keyboard, sensors, scene episode, colliders and training-mode writer only under the explicit flag. Ghosts copy transforms and enabled mesh renderers; no physics/input/sensor components are cloned. Recorded steering is interpolated onto cloned front wheel pivots using the unchanged WheelVisuals Ackermann calculation and scene wheelbase/front track width. Wheel spin is not synthesized because the telemetry does not record signed longitudinal velocity. World labels are suppressed when ghosts are within 12 m of each other; the distinct checkpoint legend remains visible. Position is linearly interpolated and quaternion rotation is spherically interpolated between adjacent recorded physics poses at 1x wall time. Once terminal simulated time is reached, the exact terminal pose is held, with FAIL/reason or FINISH badges. The whole route uses the existing fixed `PortfolioOverview` helper. No rays, new trajectory or ghost interactions occur.

Output includes real rendered PNG frames, `frames.csv` (`frame,realtime_seconds,replay_seconds,final_hold`), copied `replay-manifest.json`, and fixed camera metadata. `replay_seconds` includes the additional final display hold; the UI simulated time clamps to `durationSeconds`. For a run, its individual hold begins at its actual last CSV time and continues through the global replay endpoint. Additional final hold is explicitly marked by `final_hold`. Acquisition at nominal 20 fps may have wall-clock gaps; use the recorded timeline for media encoding and disclosure. Testing alone builds/runs Unity; no execution verification is claimed here.
