# Offline actor animation interface

`tools/render_actor_activations.py` reconstructs the preserved 15 → 64 tanh → 64 tanh → 2 tanh deterministic actor from its exact checkpoint. Input is actual recorded decision JSONL (`physics_ticks`, `episode_seconds`, `observations[15]`, `actions[2]`) or the existing evaluation NPZ with an exact decision-timeline CSV (`observation_index,physics_ticks,episode_seconds`). NPZ uses `episode_0_observations`, `episode_0_actions` and `episode_0_pre_tanh`. Every decision is mapped once in original order. Do not infer a tick offset from nominal 10 Hz cadence.

Single-row float32 CPU inference must match each recorded action and pre-tanh mean bit for bit before rendering. All 15 inputs, both 64-neuron hidden layers and both actions are shown. Circles use blue positive / red negative; water height equals absolute bounded activation. Pre-tanh means are numeric. The standard-deviation branch is disclosed as training-only and is not represented as part of deterministic evaluation.

Connections are the globally strongest 24 absolute actual weights per layer, fixed across the animation. Ties sort by source then target index. The complete layers have 960, 4096 and 128 connections; omitted connections are explicitly disclosed. These links are neither attention nor causal importance.

Testing owns fresh compact captures, exact decision timing, NPZ and outcomes. Gameplay uses the existing actual sensor overlay and `ray-samples.csv`; no extra ray queries. Align the first eleven observation fields against the same recorded normalized ray samples. Compose an offline actor panel next to actual gameplay frames, using the latest actual decision at each frame's physics tick. Record acquisition gaps, source intervals, terminal holds and resets. Raw capture frames remain outside publication. A numerical preview is not evidence for compact driving success.

The standalone concise learning diagram lives at `docs/media/compact/learning.svg`, generated only by `tools/render_compact_learning.py`; historical diagram outputs are untouched. PNG rasterization is available through the bundled read-only Node runtime and Sharp package; `docs/media/compact/learning.png` was generated and visually checked. The available archive Python runtime was used read-only for CLI validation; actual historical action reconstruction matched all 164 decisions in one preserved episode. Fresh compact seed 50007 capture reconstructed all 139 recorded deterministic decisions with bitwise actions and pre-tanh means; composition validated the same-tick ray samples against the eleven ray observations as float32. `tools/compose_actor_capture.py` validates all same-tick rays bitwise as float32, rasterizes actor panels, and composes the latest actual decision at each gameplay frame tick. `tools/encode_compact_media.py` handles recorded episode or ghost replay timestamps, full MP4/GIF decoding, hashes and explicit evidence/hold/reset/excerpt metadata.

README and accepted defaults stay unchanged until the parent accepts the compact gate. Public MP4/GIF media requires decode/hash checks and parent visual review.
